# 🧪 Playwright UI Automation Framework

## 📌 Project Description

This project is a UI automation framework for testing a website.
**https://modivo.ua/** with Playwright.

The framework is designed for end-to-end testing of user scenarios:
- verifying UI components
- testing critical user flows
- regression testing
- running tests in CI/CD

---

## 🧰 Technology stack

- **Playwright** — a modern framework for E2E testing
- **TypeScript** — typing and a better development experience
- **Node.js** — runtime environment
- **Allure Report** — visual test report generation
- **Playwright Test Runner** — built-in test runner

---

## 🚀 Test Execution

### Install dependencies
```bash
npm install
```
### Runnig all tests
```bash
npx playwright test
```
